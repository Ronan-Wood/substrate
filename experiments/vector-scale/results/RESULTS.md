## 3. Filtered search at ef = 128

Each cell is recall / short / ms. `short` = queries (of `queries`) that returned fewer than min(k, rows passing the filter), a correctness failure under substrate's every-arm rule. `post` asks for min(k / selectivity × 2, 4,096) neighbours. `planned` goes exact at ≤ 10,000 rows passing, else post-filters with an exact fallback whenever that comes back short, so it cannot be short by construction; its paths column counts exact·ann·fallback, and `ann-path recall` is its recall over the queries that took the ANN path alone. Every strategy builds the filter's mask per query inside its timing (native also builds its bitmap or callback); sqlite-vec's filter is SQL over its own tables. Strategies are interleaved per query. `(N raised)` = hnswlib calls that raised because fewer than k were found; the API returns nothing for those. Recall is tie-aware: a row scoring at least the k-th true score counts as a hit.
